# BKC Resource Graph UI Review

Review lane for the first Cytoscape-backed Resource Graph canvas.

This lane captures the feature as a BKC artifact:

- Flask graph endpoints emit Cytoscape nodes and edges.
- The Resource Graph page renders a dark interactive canvas.
- Filters keep large inventories readable.
- Map and Flow layouts support topology and narrative views.
- Right-click context actions expose node-specific operations.
- Dragged node positions are saved for later review.

The current lane is intentionally review-first. It documents the validation
surface and operator checklist while the executor path is still being shaped.
